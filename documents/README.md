# Documents

This folder contains project documents (PDF, Word, TXT, MD) used as **context** by AI agents.

## Structure

Each subfolder represents a project:

```
documents/
├── progetto-esempio/
│   ├── architettura.pdf
│   ├── requisiti.docx
│   ├── note.md
│   └── extracted-images/     ← generated by script
│       ├── architettura_p1_img1.png
│       └── requisiti_img1.png
```

## How to use

1. **Create a folder** for your project: `documents/<project-name>/`
2. **Drop files** (PDF, DOCX, TXT, MD) into the folder
3. **Extract images** (if documents contain images):
   ```bash
   pip install PyMuPDF python-docx Pillow   # first time only
   python scripts/extract-images.py documents/<project-name>
   ```
4. **Ask the agent** to read the documents — it will:
   - Read PDF text via MCP `pdf-reader` tool
   - Read TXT/MD files directly
   - View extracted images via `view_image`

## Notes

- **PDF text quality** depends on the PDF type. Native PDFs work well; scanned PDFs may need OCR.
- **Only `.docx`** is supported for Word (not legacy `.doc`).
- The `extracted-images/` subfolder is auto-created by the script.
